# Security

TravelLog's MCP server is hosted by TravelLog. This repository holds documentation only, with no code to patch.

## Reporting a problem

If you find a security problem with the hosted server at `https://travellogapp.web.app/mcp`, the sign-in flow, or the
TravelLog apps, email [armgardtj@outlook.com](mailto:armgardtj@outlook.com) with "Security" in the subject. Please
include the steps to reproduce it and, if you can, what an attacker could do with it.

- Please don't open a public issue for a security problem, and don't test against other people's accounts or data.
- You'll get a reply within 7 days. Fixes ship on the hosted server, so there's nothing for you to update.

Privacy questions: see the [privacy policy](https://travellogapp.web.app/privacy).
